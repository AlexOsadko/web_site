# Свіжа практика судів (добірка)

`tools/practice_digest.py` + `.github/workflows/practice-digest.yml`.

Щоранку (~08:12 за Києвом) бот «Судові засідання та практика» перевіряє нові офіційні
публікації **Практики ВС**, **Постанов Пленуму ВС** і **Конституційного Суду**. AI відбирає
до 3 найкорисніших для адвоката (пріоритет: ст. 130 КУпАП і адмінпроцес, сімейне право,
кримінальний процес; інші галузі — лише важливі позиції) і надсилає розбір у ваш чат із
ботом: суть, позиція суду, що це дає на практиці, номер справи (якщо є в тексті) і
посилання на текст на сайті суду. Нічого вартого — бот мовчить.

Позачергово — кнопка **«📰 Свіжа практика»** у меню бота (або `/digest`).
Пошук за темою — кнопка **«🔎 Пошук практики»** (`vs-practice.yml`).

Розбори — лише за реальним текстом публікації; AI нічого не додумує.

Нічого додатково налаштовувати не треба: використовуються наявні секрети
`TELEGRAM_BOT_TOKEN`, `TELEGRAM_REVIEW_CHAT`, `ANTHROPIC_API_KEY`, а у воркері бота —
`GH_DISPATCH_TOKEN` (той самий, що вже запускає пошук практики).

Перевірка без надсилання: Actions → «Практика судів — щоденна добірка» → Run workflow
з галочкою «Лише показати…». Стан — `.practice-bot/state.json`; перший запуск не
вивантажує архів, а розглядає лише кілька найсвіжіших публікацій.
