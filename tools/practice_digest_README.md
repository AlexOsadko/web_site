# Щоденна добірка судової практики (приватний канал)

`tools/practice_digest.py` + `.github/workflows/practice-digest.yml`.

Щоранку (~08:12 за Києвом) бот читає нові офіційні публікації **Практики ВС**,
**Постанов Пленуму ВС** і **Конституційного Суду**, AI відбирає до 3 найкорисніших
для адвоката (пріоритет: ст. 130 КУпАП і адмінпроцес, сімейне право, кримінальний
процес; інші галузі — лише важливі позиції) і надсилає розбір у приватний канал:
суть, позиція суду, що це дає на практиці, номер справи (якщо є в тексті) і
посилання на текст на сайті суду. Нічого вартого — бот мовчить.

Розбори — лише за реальним текстом публікації; AI нічого не додумує.

## Налаштування
1. Канал → Редагувати → **Тип каналу: Приватний**; за бажанням змініть назву й опис.
2. Бот, що постив новини, має лишатися **адміністратором** каналу з правом публікації.
3. Дізнайтеся id каналу: перешліть будь-який пост каналу боту **@userinfobot**
   (або @getidsbot) — він покаже число виду `-100…`.
4. GitHub → Settings → Secrets and variables → Actions → **New repository secret**:
   `PRACTICE_CHAT` = це число.
5. Перевірка: Actions → «Практика судів — щоденна добірка» → **Run workflow**
   (з галочкою «Лише показати…» — без надсилання; без галочки — справжній запуск).

Стан (уже розглянуті матеріали) — `.practice-bot/state.json`. Перший запуск не
вивантажує архів: розглядає лише кілька найсвіжіших публікацій.
