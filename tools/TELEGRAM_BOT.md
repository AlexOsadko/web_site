# Автопостинг новин у Telegram («Про право простою мовою»)

Бот бере новини з RSS-стрічок (загальні + юридичні) та ваші статті з
osadko.online, **аналізує кожну публікацію через Claude** і постить у ваш
Telegram-канал резюме **простою, зрозумілою мовою**: про що новина і що вона
означає для читача. Працює безкоштовно на GitHub Actions, нічого окремо
хостити не треба.

Формат поста:
> 📰 **Заголовок**
> Суть простими словами (2–4 речення).
> 💡 **Що це означає для вас:** значення для читача.
> ⚖️ **Порада:** на що звернути увагу / коли варто звернутися до адвоката.
> 🔗 Читати джерело · Джерело · #рубрика
> [кнопка «⚖️ Консультація адвоката»]

Якщо ключ до Claude недоступний — бот все одно працює, але постить звичайний
опис зі стрічки (без AI-резюме).

## Що зробити один раз (налаштування)

### 1. Створити бота
1. У Telegram відкрийте **@BotFather** → надішліть `/newbot`.
2. Вкажіть назву і username бота (напр. `osadko_news_bot`).
3. BotFather видасть **токен** виду `123456:AA...` — скопіюйте.

### 2. Створити канал і додати бота адміном
1. Створіть канал (Telegram → Новий канал), напр. публічний `@osadko_law_news`.
2. Налаштування каналу → **Адміністратори** → додайте свого бота.
3. Увімкніть боту право **Публікувати повідомлення** (Post messages).

### 3. Додати секрети в GitHub
Репозиторій → **Settings → Secrets and variables → Actions → New repository secret**.
Створіть два секрети:

| Ім'я | Значення |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен від BotFather |
| `TELEGRAM_CHANNEL` | `@username` каналу (або числовий chat_id) |
| `ANTHROPIC_API_KEY` | для AI-резюме простою мовою (вже доданий — ним працює генератор статей) |

> Назва каналу: **«Про право простою мовою»**. `ANTHROPIC_API_KEY` уже є в
> секретах репозиторію (його використовує генератор статей), тож окремо
> додавати не потрібно. Без нього бот працюватиме, але без AI-резюме.

### 4. Перший (тестовий) запуск
Actions → **«Новини в Telegram»** → **Run workflow**.
- Можна поставити галочку **dry_run** — тоді бот лише покаже в логах, що постив би,
  нічого не публікуючи.
- Потім запустіть без dry_run — і в каналі з'явиться перший пост.

Далі бот працює **сам щогодини**.

## Налаштування (за бажанням)

- **Стрічки новин** — файл `tools/telegram_feeds.txt` (одна на рядок,
  формат `Джерело | https://...`). Додавайте/видаляйте вільно. Якщо стрічка не
  працює — це видно в логах Actions, просто виправте адресу.
- **Темп** — `cron` у `.github/workflows/telegram-news.yml`: типово **3–4 пости
  на тиждень** (нд/пн/ср/пт), бо щоденні пости для юридичного каналу зайві.
- **Кнопка «до адвоката»** — `BOT_CTA_EVERY` (типово `4`): показується не на
  кожному пості, а кожен 4-й (правила реклами адвокатської діяльності + модерація
  Telegram Ads). `0` — ніколи.
- Інше у тому ж файлі: `BOT_MAX_PER_RUN` (постів за запуск), `BOT_MAX_AGE_HOURS`
  (свіжість), `BOT_SHOW_PREVIEW` (`0` — без прев'ю).

### Редакційна концепція (закладена в AI-резюме)
- Практичний фокус: «що це означає для людини / сторони», без цитування норм на
  пів екрана (сам закон — за посиланням).
- **Без обіцянок результату**, статистики виграшів і порівнянь з іншими
  адвокатами; про типові конструкції, а не про впізнавані справи (адвокатська
  таємниця, правила реклами адвокатської діяльності).
- CTA — рідко й ненав'язливо, цінність важливіша за саморекламу.
- **Кнопка «Написати адвокату»** під кожним постом — у workflow:
  - `BOT_CONTACT_URL` — куди веде кнопка (типово сторінка контактів
    `https://osadko.online/kontakty/`; можна поставити свій Telegram,
    напр. `https://t.me/your_username`, або Viber/WhatsApp);
  - `BOT_CONTACT_LABEL` — напис на кнопці.

## Як це працює

- Раз на годину GitHub Actions запускає `tools/telegram_news_bot.py`.
- Скрипт читає стрічки, бере найсвіжіші ще не опубліковані новини (до
  `BOT_MAX_PER_RUN` за раз і не більше `BOT_DAILY_MAX` на добу) і постить у канал.
- Перелік уже опублікованих зберігається у `.telegram-bot/state.json`, щоб не
  дублювати. Цей службовий коміт не перезапускає деплой сайту.

Новини публікуються з **посиланням на джерело** (заголовок + короткий опис),
тому це коректний формат агрегатора, а не копіювання чужого контенту.
