# Заявки з форм → Telegram (osadko-relay)

Код: [`worker.js`](./worker.js). Воркер у Cloudflare — **osadko-relay**,
бот «osadko.online_Заявки». Той самий воркер зберігає зашифрований реєстр
договорів (`/registry`) для генератора договорів.

Токени й ключі — лише в секретах воркера (список у шапці `worker.js`), у коді їх немає.

## Що приходить у заявці

Назва форми, імʼя, телефон, повідомлення, а також джерело візиту, яке визначає
`assets/site.js`:

- 📣 **Канал** — Google Ads (є `gclid`), значення `utm_source`, Пошук, Соцмережі,
  Інший сайт або Напряму; кампанія — з `utm_campaign`, якщо є;
- ↩️ **Звідки** — сайт, з якого прийшли, і перша сторінка візиту;
- 🆔 `gclid` — під спойлером.

Джерело зберігається лише в `sessionStorage` до кінця візиту.

## Оновлення

Відкрити raw-файл `worker/relay/worker.js` з `main` → Cmd+A / Cmd+C →
Cloudflare → osadko-relay → Edit code → вставити → Deploy.
