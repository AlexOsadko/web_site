# Чат на сайті → Telegram

Відвідувач пише у віконце на сайті, повідомлення приходить вам у Telegram від
окремого бота. Ви відповідаєте **реплаєм**, і відповідь з'являється в чаті на сайті.
Якщо зараз активна лише одна розмова, можна писати й без реплаю.

Усе безкоштовно (Cloudflare Workers + D1). Листування зберігається 30 днів після
останнього повідомлення, потім видаляється автоматично.

Код воркера: [`worker.js`](./worker.js). Віджет на сайті: `assets/chat.js`.

## Крок 1. Бот у Telegram (2 хв)
1. Відкрийте **@BotFather** → `/newbot`.
2. Назва: `Чат сайту osadko.online`; username: напр. `osadko_site_chat_bot`.
3. Скопіюйте **токен** (виду `123456:ABC...`).

> Потрібен саме **новий** бот: у бота може бути лише один вебхук, а наявний
> бот каналу вже працює через інший воркер.

## Крок 2. База D1
**dash.cloudflare.com → Storage & Databases → D1 → Create database**, назва
`osadko-chat` → Create. Таблиці воркер створить сам.

## Крок 3. Воркер
1. **Compute (Workers) → Create → Worker**, назва `osadko-chat` → **Deploy**.
2. **Edit code** → видаліть шаблон, вставте весь вміст `worker.js` → **Deploy**.
3. **Settings → Bindings → Add → D1 database**:
   Variable name **`DB`**, база `osadko-chat` → Save.
4. **Settings → Variables and Secrets** → додайте:

| Ім'я | Тип | Значення |
|---|---|---|
| `CHAT_BOT_TOKEN` | Secret | токен з Кроку 1 |
| `WEBHOOK_SECRET` | Secret | будь-який довгий випадковий рядок (придумайте) |
| `OWNER_CHAT` | Text | ваш Telegram id — той самий, що `REVIEW_CHAT` в іншому воркері (або див. Крок 5) |
| `TURNSTILE_SECRET` | Secret | *опційно*: той самий секрет Turnstile, що у воркері `osadko-relay` (антиспам) |

Після додавання — **Deploy**.

## Крок 4. Підключити бота
Відкрийте в браузері (підставте адресу воркера і свій `WEBHOOK_SECRET`):

```
https://osadko-chat.<ваш-акаунт>.workers.dev/setup?key=<WEBHOOK_SECRET>
```

Має показати `✅ Готово` та ім'я бота.

## Крок 5. Перевірка
1. Напишіть новому боту `/start`. Він має відповісти «Бот чату на сайті працює ✅».
   Якщо `OWNER_CHAT` ще не задано, бот надішле ваш id: впишіть його в `OWNER_CHAT`
   і натисніть **Deploy**.
2. Надішліть адресу воркера: її впишуть у `assets/chat.js` (`ENDPOINT`), і чат з'явиться на сайті.

## Як користуватися
- Нове звернення: `💬 Чат із сайту · #K7Q2`, сторінка (з посиланням), текст. Під ним кнопки **📋 Уся розмова** і **🗑 Видалити**. Відповідайте **реплаєм**.
- Залишений контакт: `📞 #K7Q2 залишив контакт: …`.
- Якщо відповідь не вдалося передати на сайт, бот напише чому; якщо все гаразд — мовчить.
- Коли клієнт відкрив чат на сайті й побачив вашу відповідь, бот ставить на неї 👀.
- Кнопки внизу чату з ботом: **📋 Розмови** (останні розмови кнопками — натисніть, щоб переглянути все листування) і **❓ Як відповідати**. Якщо кнопок не видно — надішліть `/start`.
- Видалення завжди з підтвердженням («🗑 Так, видалити» / «Скасувати»).
- Команди теж працюють: `/list`, `/view` і `/del` (реплаєм на повідомлення клієнта).
- Клієнт на сайті може почати **нову розмову** або **видалити** свою (меню «⋯» у вікні чату); про видалення бот повідомить.
- Кнопки й команди працюють лише у вашому чаті з ботом (`OWNER_CHAT`); іншим бот відповідає, що він службовий.
- Підтримується лише текст (фото й файли — ні).
- Якщо відвідувач закрив сторінку, відповідь він побачить, коли повернеться на сайт
  з того ж браузера. Тому для важливого зв'язуйтеся за залишеним контактом.
